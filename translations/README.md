# Переводы

## Тексты интерфейса — `ui/<язык>.json`

Каждая строка: `"ключ": "текст"`. Ключи во всех языках одинаковые, меняются только тексты.
`{n}`, `{year}`, `{i}` подставляются программой, их не переводить и не удалять.
Если какого-то ключа в языке нет, будет показан английский текст.

## Названия стран — `names/<язык>.json`

Простая таблица «английское название из данных → перевод»:

```json
{
  "Ottoman Empire": "Османская империя",
  "Grand Duchy of Moscow": "Великое княжество Московское",
  "Inca Empire": "Империя инков"
}
```

Перевод не обязательно делать полным: для отсутствующих названий показывается английское.
Ключ должен совпадать с полем `NAME` в данных буква в букву.
Полный список названий по годам есть в исходных данных (`tools/.cache/historical-basemaps/index.json`
после запуска `npm run build-data`) или можно собрать из `data/borders/*.json`.

Если у названия есть перевод, ссылка «Читать в Википедии» ведёт в Википедию на этом языке.

## Примечания к зонам культур — `notes/<язык>.json`

Тексты, которые показываются в карточке зоны. Ключ — поле `NOTE` в правиле `add` (`corrections/corrections.json`).
Если для языка примечания нет, показывается английское.

## Добавить новый язык (например, немецкий)

1. Скопировать `ui/en.json` в `ui/de.json` и перевести тексты.
2. Поменять в нём `wikipediaHost` на `de.wikipedia.org`.
3. Добавить строку в `languages.json`: `{ "code": "de", "short": "DE", "label": "Deutsch" }`.
4. (Необязательно) создать `names/de.json` с переводами названий и `notes/de.json` с примечаниями.

Код менять не нужно.
