> этапа обновляй этот файл (разделы «Сделано», «Текущее состояние», «Следующие шаги»).
>
> **Где что лежит (21.10):** в проекте claude.ai — только копия этого файла. Очереди (`corrections/queue-*.md`), архив
> очередей, история этапов и всё остальное — только в папке проекта на компьютере владельца: чат должен быть связан с компьютером.
>
> **Общаемся на «ты»** (владелец, 21.10). Никаких правок без прямой команды «применяй» (см. `CLAUDE.md`).
>
> **Горизонт применения (владелец, 21.10):** разбирая зону, сразу записываем в очередь строку «Горизонт:» — на каких
> следующих картах (6000\*, 5000, 4000, 3000 …) она стоит и в каком виде, где кончается и почему. На следующей карте такие
> зоны переносим по записи, без повторного разбора (заново — только при новых данных или если край горизонта в окне ±250 лет).
> Уже разобранные зоны задним числом не перепроверяем — горизонт им пишем, когда до них дойдём. Подробно — `corrections/README.md`.
>
> **Даты и контур — при разборе (владелец, 21.10):** у каждого нового пункта очереди, до решения владельца, — строка
> «Даты: сверено …» (даты как в источнике + источник; все «сверить» закрыты) и строка «Контур:» (словами — для владельца,
> без градусов; для построения — памятники с координатами и правило границы). При применении такой пункт строится по записи,
> без повторного поиска (заново — только при новых данных или противоречии). Превью не делаем. Южную Америку карты 8000
> (3-75 … 3-87) и более ранние пункты применяем по-старому. Подробно — `corrections/README.md`.
>
> **Разбор — в чат (владелец, 24.10):** после разбора новые пункты очереди выводятся в чат текстом: номер и зона, факты кратко,
> предложения Claude, решения владельца, контур словами, горизонт (координаты — только в очереди). Подробно — `corrections/README.md`.
>
> **Правило о длине чата (владелец, 20.10):** следи за длиной чата. Когда он становится длинным настолько, что
> продолжать дороже, чем начать заново (каждое сообщение перечитывает всю историю), — предложи открыть новый чат,
> лучше всего на естественной границе (закончена часть света, применён пакет). Перед этим обнови этот файл и очередь,
> чтобы новый чат мог продолжить с них.

## Цель

Интерактивная историческая карта мира: карта плюс ползунок времени. Двигаешь
ползунок и видишь, как менялись границы государств и культур. Клик по стране
показывает информацию о ней.

- Карта мира (проекция Natural Earth), масштаб колесом или щипком, перетаскивание.
- 54 исторические карты: от 123 000 г. до н. э. до 2010 г. (данные historical-basemaps).
- Ползунок по доступным картам, кнопки «назад/вперёд», автопроигрывание, стрелки ← → на клавиатуре.

  Выбор сохраняется при смене года; если страны на карте нет, карточка так и говорит.
- Ссылка на год: `index.html#y1492`, для до н. э. `#y-500`.
- Интерфейс на двух языках (EN/RU), переключатель в шапке, выбор запоминается.
  Названия стран пока только английские (так решил владелец); механизм перевода названий готов.

## Принятые решения и почему

| Решение | Почему |
|---|---|
| **Никаких правок без прямой команды владельца** (18.10) | Всё сначала ставится в очередь с объяснением; применяется только после явного «применяй». При сомнении — переспросить. |
| Статус «принято» — только по решению владельца (19.10) | Свои предложения Claude помечает «предложение Claude — ждёт решения», иначе владелец их пропускает. |
| Горизонт применения записывается сразу при разборе зоны (21.10) | Чтобы не разбирать одну и ту же зону заново для каждой следующей карты; уже разобранные — дописываются, когда до них дойдём. |
| Даты («сверено») и контур (словами + для построения) записываются при разборе, до решения владельца (21.10) | Раньше одну зону проверяли по 2–3 раза (разбор, очередь, применение) и искали координаты заново при построении; теперь применение — по записи. Владелец градусы не проверяет, поэтому контур описывается ещё и словами. Превью не нужны. |
| Окно ±250 лет — на подтверждение владельцу (20.10) | Карта — снимок на дату, но даты неточны и культура живёт дольше своих находок; спорные края решает владелец по аргументам. |
| Знаков вопроса на карте нет (20.10) | Сомнения — в примечании карточки, решение — за владельцем. |
| Памятник внутри культуры — в карточку, а не отдельной зоной (20.10) | Иначе карта пестрит точками, которые повторяют ту же культуру. |
| Частично разобранная карта: «Нет данных» только в разобранных частях света (20.10) | Иначе неразобранный мир выглядел бы «проверенным и пустым». |
| Клик выделяет только одну область группы, а не все (20.10) | У областей одной группы разные примечания; подсветка всех выглядела бы так, будто карточка относится ко всем. |
| Штриховка и полосы — линии с `<clipPath>`, а не `<pattern>` (20.10) | Узорные заливки давали мусор в Chrome на Android. |
| **Лицензия всего проекта — GPL-3.0** (владелец 26.10) | Данные границ (historical-basemaps) под GPL-3.0, и всё собранное из них обязано быть под ней же; одна лицензия на код и данные проще смеси. |
| Публикация — GitHub Pages (владелец 26.10; план — `corrections/queue-site.md`, С-1) | claude.ai из России недоступен; GitHub Pages бесплатен, даёт историю версий; Netlify, Vercel, Cloudflare Pages из России работают плохо. |
| Без сборщика и фреймворков: чистый HTML + ES-модули | Проще понять и править; ничего не нужно компилировать. |
| d3 + topojson-client лежат локально в `src/vendor/` | Работает без интернета, не зависит от CDN. |
| SVG, а не Canvas | До ~2000 фигур SVG справляется; проще клики и стили. Если будет тормозить, переходить на Canvas. |
| Ползунок шагает по доступным картам, а не по годам | В данных только 54 снимка; интерполяции границ нет. |
| Цвет считается по хэшу имени державы (SUBJECTO) | Цвет стабилен во времени без ручной таблицы цветов. |
| Одна палитра из 18 цветов для государств и культур (3-87, 21.10; применено 22.10) | В старой палитре из 12 цветов несколько пар были почти неразличимы; одна палитра проще двух. |
| Цвет культуры — вручную в `corrections/colors.json` (3-70, 20.10) | Хэш не знает соседей: разные соседние культуры получали один цвет. Одна культура — один цвет на всех картах. |
| Поле `GROUP` у наших зон — общий цвет для одного населения | Зоны Австралии различаются только местом, а население одно; в карточке поле не показывается, чтобы не писать «под властью». |
| Названия стран: ключ = английское имя из данных | В данных нет ID; английское имя единственное общее поле между эпохами. |
| Состояние года в адресе вида `#y1492` | Работает и на хостинге claude.ai, где допустимы только буквы, цифры и «-». |
| Поправки — правилами в `corrections/`, а не правкой готовых файлов | Переживают обновление исходников; видно, что и зачем изменено. Правила ищут фигуры по точке и названию, а не по номеру в файле: номера меняются при обновлении. |
| Наши зоны добавляются после упрощения | Иначе маленькие зоны (эбурри, Железные Ворота) упрощались до треугольников. |
| Древний берег — по сетке ETOPO1 10′, с заливкой океана от Тихого океана | Одинаково и честно для всего мира; закрытые водоёмы (Каспий, Мёртвое море) не «осушаются». |
| «Нет данных» только на разобранных картах | На неразобранных и поздних картах пустая суша значит другое («нет государства»). |
| Земли под ледниковыми щитами — «Не заселено» | Надёжно установленный факт; лёд при этом не рисуется (решение владельца), только помечается суша. Горные ледники не помечаются. |
| «Вилка ±1000 лет» | Если находки той же культуры есть и раньше, и позже даты карты в пределах 1000 лет и нет признаков ухода людей — культура считается существующей без примечания: погрешность дат сама порядка сотен лет. |
| Реки и озёра — современные на всех картах, продлены по шельфу на древних | Точных древних русел никто не знает; продление по уклону дна правдоподобно и честно помечено пунктиром и пометкой под годом. |
| «Не заселено» — только надёжно установленное | Это утверждение о прошлом, а не пробел в данных; спорные случаи (Мадагаскар, Крит) — «Нет данных». |
| Примечания — ключом, тексты в `translations/notes/` | Примечания переводятся так же, как интерфейс. |
| Документация на русском, комментарии в коде на английском | Владелец читает по-русски; английские комментарии привычны любому ИИ и разработчику. |
| Одна культура — один контур; расширение — правкой контура | Иначе на карте видны внутренние границы и одна культура выглядит как несколько; сборка сливает куски одного файла сама. |
| Реки под ледниками прячутся слоем-покрышкой, а не SVG-маской | Маска давала визуальный мусор в Chrome на Android. |
| Карта 1 — «по вероятности», окно 135–110 тыс. лет назад (18.10) | Для 125 тыс. лет назад археологии мало и погрешность дат — тысячи лет; правило карты 2 «строго на дату» здесь бессмысленно. |
| Карта 1: вид — цвет, культура — оттенок, пересечения — полосы (18.10) | Главное на этой карте — какие виды людей где жили; культуры вторичны; полосы честно показывают, что жили оба. |

## Известные ограничения

- Реки и озёра современные; из исчезнувших озёр показано только Агассис на карте 8000 (контур приблизительный); Мега-Чад и
  смены русел (Хуанхэ, Амударья) пока не показаны. Современные реки Манитобы рисуются поверх озера Агассис.
- **Карта 8000 разобрана частично:** не разобрана только Азия (там пока данные исходника, без штриховки).
- **Шум на телефоне:** исправление (линии вместо узоров) сделано 20.10; на настоящем Android ещё не проверено.
- Низины ниже уровня моря, не связанные с океаном на сетке 10′ (дельта Сакраменто, части Сундского шельфа), на древней карте
  остаются водой (так строится берег: замкнутые котловины не «осушаются»). Мелкие ошибки, на глаз почти не видны.

- Цвета государств выбираются по названию без учёта соседей, поэтому соседи иногда одного цвета
  (например, Германия и Австро-Венгрия в 1914). Возможное улучшение — раскраска с учётом соседства.
  У культур Азии и Европы карты 10 000 цвета пока тоже по хэшу (Европа карты 8000 и три культуры Северной Америки — вручную с 24.10) — сборка печатает предупреждения
  (`colour …`); Северная Америка — пункт 3-71.
- Только 54 снимка: между ними карта «прыгает».
- При сильном приближении границы угловатые (упрощение до 8%).
- Данные historical-basemaps — работа в процессе: есть ошибки и пробелы (например, в 323 г. до н. э. почти пустая Европа).
- Названия стран только английские.
- Шрифты грузятся с Google Fonts; без интернета будут запасные шрифты (карта при этом работает).
