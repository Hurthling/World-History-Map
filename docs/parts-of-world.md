# Части света по картам

Части света задают только порядок разбора и группировку чатов; зоны рисуются целиком, через любые границы (`CLAUDE.md`, п. 8). Где не сказано иначе — обычная география. Новая карта — новый столбец; с ≈ −3000 сюда же добавится пометка «историческая / доисторическая часть» у территорий.
