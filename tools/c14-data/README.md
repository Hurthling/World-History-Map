# Радиоуглеродные даты для разбора карт

Используется скриптом `tools/c14.mjs` (как запускать — в шапке скрипта и в `corrections/README.md`).

| Файл | Что это | Источник |
|---|---|---|
| `p3k14c.csv.gz` | ≈ 175 тыс. радиоуглеродных дат с координатами (весь мир) | p3k14c, версия 2025.07 (R-пакет `people3k/p3k14c` на GitHub, файл `data/p3k14c_data.rda`); Bird et al. 2022, *Scientific Data* 9:27, doi:10.1038/s41597-022-01118-7. Данные — CC0 |
| `intcal20.14c` | калибровочная кривая северного полушария | Reimer et al. 2020, *Radiocarbon* 62 (копия из R-пакета rcarbon) |
| `shcal20.14c` | калибровочная кривая южного полушария | Hogg et al. 2020, *Radiocarbon* 62 (копия из R-пакета rcarbon) |
| `import-p3k14c.py` | как `p3k14c.csv.gz` получен из `.rda` (на случай обновления базы) | — |

Ограничения: в базе есть не всё (особенно новые работы и Россия); резервуарный эффект морских образцов не учитывается
(скрипт помечает раковины ⚠); перерывы внутри последовательности стоянки скрипт не ищет — смотреть глазами.
Это помощник при разборе: решение о зоне по-прежнему принимается по источникам и правилам из `corrections/README.md`.
